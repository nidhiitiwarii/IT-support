##Client Churn Risk and Revenue Forecasting in Managed IT Services##

About the Project

The project is based on a problem that exists in real life. The goal is to find out which clients can potentially leave the company (churn) and forecast future trends in business revenue based on data analytics.

Managed IT Services company offers the following services:

Infrastructure management

Migration to cloud platforms

Security services

Round-the-clock IT support


The project allows making more rational business decisions and predicting trends in customers’ activities and revenue of the company.


---

Project goals

Finding out which clients have a high risk of churn

Determining the behavioral patterns of the customers

Forecasting future business revenues

Making better business decisions

Increasing customer loyalty

Dataset Description

The dataset consists of such significant business features as:

Client Type

Monthly Revenues

Duration of contract

Number of tickets raised per month

Number of violations in SLA (Service Level Agreement)

Customer satisfaction score

Usage of services

Renewal status

Churn status


All of them help in understanding the level of customers’ involvement into work with the company and their loyalty to the company.
Workflow of the Project

1. Data Cleaning

During this stage:

Handling missing values

Removing duplicates

Proper formatting of data


2. Exploratory Data Analysis (EDA)

Through data visualization and analysis, the aim is to:

Identify patterns of churn

Trends in revenue generation

Relationships between variables

Segmentation of customers


3. Feature Engineering

For encoding categorical variables and scaling numeric features for improved modeling.


4. Building Machine Learning Models

Several machine learning algorithms were implemented to forecast churn, namely:

Logistic regression

Random forest classifier


Model evaluation measures include:

Accuracy

Precision

Recall

F1 score


5. Revenue Forecasting

Analyzing revenue trends for predictions of future growth of the firm.
